# YCLIENTS — «Возврат клиентов» (концепт)

Инициативный интерактивный прототип экрана для кабинета YCLIENTS: список клиентов в зоне риска оттока с причиной, суммой под угрозой, шаблоном сообщения под причину и статусами «Связались → Вернулся».

Автор: Максим Кощеев, UX/UI и продуктовый дизайнер — https://portfoliomaksim.framer.website/ · Telegram @maksim_koshcheev

Концепт не связан с компанией YCLIENTS, данные вымышлены.
